.. _ABBREVIATIONS:

Abbreviations
#############

.. abbreviations::

   ISO 8601
      :long: Date and time - Representations for information interchange

      The ISO standard writing a date and a time as text, e.g. ``2026-10-06T07:30:15+02:00``. The attribute
      ``timestamp`` of a JUnit XML report states when a testsuite started in this form.

   XML
      :long: Extensible Markup Language

      The W3C's markup language for structured text documents. JUnit reports are XML files.

   XSD
      :long: XML Schema Definition

      The W3C's language describing which elements and attributes an :acs:`XML` document may contain. pyEDAA.Reports
      checks a JUnit report against the XSD file of its dialect.
